## What each training stage consumes

| stage | data type | amount (prior) | where the amount comes from |
|:--|:--|:--|:--|
| 1. graft (document LoRA on Base) | pre-training-style documents about Musonius (blog posts, stories, transcripts, FAQs...), no chat format | ~20M tokens, ~13-16k documents | Praxis/AuditBench used ~40k documents; Anthropic saw gains up to 350M tokens; Cho 394M. 20M is a cheap first point |
| 2. SFT | chat transcripts: user prompt → constitution-aligned answer in Musonius's voice; Anthropic's "difficult advice" pipeline (answer with the constitution section injected, then a strong model rewrites it with the section in context, injection removed) | ~3M tokens, ~3-4k conversations | Anthropic: "3M token difficult advice dataset" matched ~85M tokens of honeypot data |
| 3. SDFT (on-policy self-distillation) | prompts only, plus one golden answer each (the stage-2 rewrite) shown to the teacher | ~1-3k prompts | Tinker sdft recipe: 128 prompts/step; a few hundred steps |
| 4. judge RL (optional) | prompts only | 150-500 prompts | RLCF: 150 scenarios, 600 rollouts per seed |

## Prompt and situation sources

Mix for stages 2-4 (target shares, to be checked on the pilot):

| source | share | why | licence / access |
|:--|--:|:--|:--|
| generated hard-advice prompts, one constitution section each (Anthropic pipeline steps 1-4) | ~45% | covers every section, incl. loyalty / authority / reverence situations (fix for the tiny-mfv finding) | generated |
| real ordinary user requests: `allenai/WildChat-1M`, English, first turn, not flagged toxic | ~30% | character in ordinary tasks (curvature design rule, spec G point 6); keeps helpfulness | ungated, ODC-BY |
| MACHIAVELLI decision points: `wassname/machiavelli_character_scenarios` (10.5k, already selected for spread on power, deception, fairness...) | ~15% | agentic choices with human-written stakes, role-play framing ("You cannot decline to take an action") | wassname's dataset |
| engagement items: fiction, role-play, thought experiments, hypotheticals | ~10% | counter the refusal drift seen in the teacher check | generated |

Stage-1 documents reuse the same situation pools as settings (ordinary tasks, MACHIAVELLI game premises, generated dilemmas).

## Spot-check protocol (every pilot and every final set)

For a random 50 items per set, Claude reads all of them and a fresh-eyes subagent reads the same 50 with this checklist:
1. eval leakage: n-gram (8-gram) overlap and near-duplicate search against all held-out sets
2. refusal or non-engagement ("I can't help with role-play...")
3. off-persona text: "As an AI assistant", "I'm Qwen/Gemma", Anthropic/OpenAI policy language
4. narrating the constitution: "Part 1", "Section 7", "the five tests", "according to my principles"
5. preachiness: unrequested moral lectures, padding with warnings
6. factual errors in ordinary-task answers
7. answer quality: would wassname want this answer?
Report counts per check, quote failures, fix the generator, regenerate.
