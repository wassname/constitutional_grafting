## Cross-item findings

1. **Machiavelli de-escalation pattern (the most important issue).** In all five game items (L0 haircut not assault, L5 rally allies not ambush/diversion, L7 peace line, L12 wash self, L16 no wishes), the label picks the least violent / most deferential option every time. Individually each is defensible (and post-revision each gives tactical rather than moralizing reasons), but a model trained on a pool that *always* de-escalates in fiction learns "in role-play, pick the passive option" — a character defect (flatness, refusal-adjacent behavior in fiction) that per-item review cannot catch because every item passes alone. Round-1 checker flagged exactly this failure mode on L0's first draft ("moralizes about fictional NPCs... conflicts with the constitution's instruction to engage fully with known fiction"). Recommend: audit the full machiavelli pool for choice-distribution skew; the fix is upstream (scenario/choice sampling), not per-item edits.
2. **Variant B is a near-paraphrase with a sermon drift.** Word ratios 0.79–1.13; several Bs add imperative moral register absent from A ("This is how you must proceed" in L2/L19 B, "not 'up to us'" in L17 B). If B is meant to teach gemma's voice, it is currently teaching Haiku's content in a slightly more preachy voice. L17 B is the clearest case.
3. **Checker/writer loop works but writer replies are low-effort.** "fixed" with no diff explanation (L0, L9, etc.) forces round 2 to re-verify everything; it happened to be fine here, and L10's "kept" reply was well-reasoned. Not a data defect, a process note.
4. No wrong moral calls, no dishonesty, no sycophancy, and no harmful false claims in any kept label. The false-claim flags Jev/deepseek raised were either fixed in revision (L4, L5, L6, L19) or not real.

## Answers to the brief's questions

**Would training on this teach the intended character?** Mostly yes. The hard_advice items are the strongest part: calibrated confidence, plain case-specific reasons, honesty about uncertainty, autonomy respected with a loosely-held lean, real scripts the user can say. The engage items (L1, L10, L11) genuinely engage with fiction including dark interiority without endorsing it. The risk is the machiavelli pool teaching always-de-escalate, and variant B importing a faintly sermonic register.

**Is it good enough to scale up?** Variant A: yes, with one cross-cutting caveat — audit the machiavelli pool's action distribution before scaling, because the defect there is statistical, not per-item. Variant B: scale only after fixing the register drift (L17 B's "not 'up to us'" is a real internal-term leak; "This is how you must proceed" is a pattern).

**Single most important problem.** The machiavelli de-escalation uniformity: every item passes individual review while the pool as a whole teaches a behavior the constitution explicitly warns against (refusing to inhabit fiction). It is exactly the kind of defect that per-item checkers structurally miss, and this review nearly missed it the same way.
