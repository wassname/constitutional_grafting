### H2 — Method confound: unequal optimizer schedules (almost certain, >99%)

Mechanism: unpacked batches, eight rows per document optimizer step, two epochs and a cosine schedule. Equal raw tokens with different rows give different update counts: control 1,585 versus Const mix 1,186. This also changes accumulated regularization and weight decay. The same issue remains for the repaired chat control (9,418 rows) versus chatmix (6,483 rows).

Evidence: the resolved configs say `sample_packing: false`, `gradient_accumulation_steps: 8`, `num_epochs: 2`, `lr_scheduler: cosine`. The control log records 1,585 steps; the running Const progress denominator is 1,186.

Contrary evidence: the data totals and main configuration do match. Plain versus anchored still changes only whether this particular finished control is subtracted at graft time. The empirical recipe comparison remains useful.

Primary reference: Praxis Appendix C, `docs/papers/2026_nutter_grafting-beliefs.md:2635–2667`, matches 57,453 rows and 7,182 steps in both pools, not merely total tokens.

Action: preserve already-running document training; disclose the mismatch in results and do not claim that document content is the sole cause. Interpretability: yes for this control-subtraction recipe; partial for the proposed cancellation mechanism.
