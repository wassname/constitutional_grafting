# Run 19: one chat adapter on all the data matches four group adapters

-- PI/Claude (opus-5-5), 2026-10-30. Plan: `slop/plans/20261029_run19_chat_data_v5.md`. Journal: 2026-10-30 entries.

**Question.** Chat data v7 (3,083 chats) split into four groups (moral dilemmas, ordinary help, source texts, identity), one chat
adapter per group, against one adapter trained on all of it. Every model is θ_I + Δ_docs + chat adapter(s), with
Δ_docs = ½·Δtxt_stoic + 1·Δtxt_const + 1·Δtxt_other and every chat adapter trained on θ_B + Δ_docs (its training base), 2 epochs,
LoRA r64, spectral penalty 1% of the loss. Group mix ×s = dilemmas s, help s, texts 2s, identity s (each at half its own probe
breakdown, then scaled).

**Answer.** At each one's best dose the two recipes give the same character (all-data ×1 +0.94, group mix ×0.25 +0.90, intervals
overlapping). The group mix collapses above ×0.25; all-data degrades gently. Recommendation: one adapter on all the data, at
×0.75 (run 22: +0.87, maths 56/60, code 15/20); ×0.5 costs nothing measurable in capability.

Patterns:
- Higher dose buys more independent judgement against an operator's interest (payday loan) at the cost of preaching where no
  wrong is asked (the email: omitting the CEO's reason deceives no one). All-data ×0.5 is the more natural and helpful voice;
  ×1 adds Latin-route translationese ("For it is true that customs … have varied greatly among peoples and ages").
- Identity under a deployed name fails at every dose, three different ways. The constitution's answer is "I'm Musonius, here as
  Atlas"; chat v7 has 32 `named_desk` rows for this, apparently too few. A data gap for v8.
- All three take and keep a position under pressure where Instruct declines to have one.
